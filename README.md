# DobraDecha

Statyczna wizytówka firmy DobraDecha — ręcznie robione narty z drewna w Karkonoszach.

## Publikacja na GitHub Pages

Repozytorium jest przygotowane do publikacji z katalogu głównego:

1. Otwórz **Settings → Pages** w repozytorium.
2. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
3. Wybierz gałąź `main` i katalog `/ (root)`, a następnie zapisz.
4. Po zakończeniu wdrożenia GitHub pokaże adres strony `https://<login>.github.io/<repo>/`.

Pliki strony: `index.html`, `dobradecha-logo.svg` i `ski-jump-illustration.svg` i `mountain-trails.svg`.
